# v0.15.1 — 公开仓 `pytest` 开箱 45 红

> 日期：2026-08-22。测试改动，**产品行为一行不动**，插件 semver 不动。

## 病

公开仓干净 checkout 上 `python -m pytest pen/tests -q` → **45 failed / 432 passed**。

根因一条：`pen/config.py:34` 的 `DEFAULT_HANDBOOK = REPO_ROOT / "SWE-Agent通关手册v2.md"`
在公开仓里**不存在**（那是实验室仓的教材，按 v0.14.0 的决定不进公开仓）。
`libraries.ensure_default()`（`libraries.py:127-134`）因此空操作返回 `None`，
所有拿默认手册当地基的测试全塌：

| 文件 | 红 | 根因 |
| --- | --- | --- |
| `test_app.py` | 36 | 29 条 `KeyError: 'session_id'`（建会话 404）+ 5 条 `FileNotFoundError` + 2 条断言 |
| `test_tutor.py` | 4 | `libraries.load_index("swe-agent-v2")` → `KeyError` |
| `test_retention.py` | 2 | 同上 |
| `test_i18n.py` | 2 | 同上 |
| `test_diagnose.py` | 1 | 同上 |

实验室仓 477 全绿——那本书在，掩盖了这条依赖。

**为什么现在治**：v0.15.1 的 README 大修要在「开发 · 测试」一节叫读者跑 `pytest`。
让人跑一个开箱就 45 红的套件，等于交一份坏活。

## 改法

### 1. 新增 `pen/tests/fixtures/default_handbook.md`

一本极小的合法通关手册，走 `pen/index.py` 的确定性索引格式（八拍 + `〔回读：…〕` 收束），
含 `开篇` / `Level 0` / `Level 1` / `最终通关任务` / `附录`——`附录` 是必需的，
`test_tutor.py` 的目录断言点名要它。

**不复用现成的 `mini_handbook.md`**：那本被 8 个测试文件当输入，
往里加 `附录` 会动到 `test_index.py` 的 section / toc 计数断言。新开一本，互不干扰。

### 2. `pen/tests/conftest.py` 无条件把默认手册指到这本 fixture

`DEFAULT_HANDBOOK_ID` 保持 `swe-agent-v2` 不变——测试只断言 **id**，不断言书的内容
（`test_app.py:43`、`:591`）。两个名字都要 patch：`pen/libraries.py:11` 是
`from pen.config import DEFAULT_HANDBOOK`，import 时就冻住了，只 patch `config` 够不着。

**无条件**而不是「真书不在时才兜底」：条件分支会让两个仓跑的是不同的测试，
同一份 `pen/` 却有两种行为，那比现在这条病更难查。

### 3. 拆掉 `test_tutor.py` 里写死的 `start_line=544, end_line=545`

那两个数只在 13083 行的实验室教材上成立，换任何一本短书都会撞
`ValueError: 行号越界`。改成从索引推——测试要验的是目录段和书架段，跟具体哪一行无关。
