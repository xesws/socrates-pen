# v0.16.5 — Hero 换成标语，底色改紫

> 日期：2026-08-22。只动 `README.md` / `README.en.md` / `docs/` / `scripts/render-hero.py`。
> `src/` `pen/` `styles.css` `manifest.json` `versions.json` 一行不动，不发 Release。
> 插件 semver 仍是 `0.13.1`。

## 病在哪

Hero 卡片右栏原来是「字标 → 分隔线 → 副题 `Socrates-agent` → 密度阶 `. : s A 3 G & @`」。
两处不对：密度阶是**画法说明**，对着 README 的人不需要知道这幅画用了哪八个字符；而底色
是照搬插件的 `color-mix(accent 16%, #1E1E1E)`，尾段褪成中性灰，跟 §2 起那批界面截图里
一水儿的紫不是一个色系。

层级也是反的。插件里 `styles.css:613-633` 明写标语在副题**之上**、`font-weight: 600`、
`letter-spacing: 0.34em`，副题只有 10px 且用 `--text-faint`；hero 却把最不重要的密度阶
放在最下面当收尾，等于把插件自己的主次颠倒过来复制了一遍。

## 改成什么

**密度阶换成标语。** 文案不另起炉灶，直接取插件 i18n 里那一条：中文 `src/i18n/zh.ts:168`
的 `苏格拉底学习法`，英文 `src/i18n/en.ts:128` 的 `The Socratic Method`。右栏改成
「字标 → 分隔线 → 标语 → 副题」，字号、字重、字距按 `styles.css` 那两条规则等比放大到
hero 的 20px / 12px。

**底色改成全程紫。** `ACCENT` 不是拍脑袋调的，是从 `docs/img/shot-01-splash.png` 里量出来
的最常见饱和紫 `#8A5CF6`（出现 260 次，就是「问」按钮和状态点的颜色），hero 和界面截图
因此是同一个色系。插件那条 `color-mix` 公式原样保留，只把兑进去的底色从中性灰 `#1E1E1E`
换成染过紫的 `#241E30`，比例从 16%/4% 提到 24%/7%：

| 档位 | 渐变 | 说明 |
| --- | --- | --- |
| `violet-deep`（默认，仓里这张） | `#3C2D60 → #2B223E → #241E30` | 全程紫，尾段不褪灰 |
| `violet` | `#33284B → #262032 → #221E2A` | 同色系淡一档 |
| `faithful` | `#2F2841 → #222027 → #1E1E1E` | 照搬插件公式，前紫后灰 |

边框 `rgba(138,92,246,0.22)`、分隔线 `rgba(138,92,246,0.30)` 跟着 `ACCENT` 走。

**中英各一张图。** 上一版 hero 里刻意一个汉字都没有，为的是中英共用一个文件；这一版
标语进了图，共用就意味着英文 README 顶上顶着一行中文。所以出两张：`docs/img/hero.png`
和 `docs/img/hero.en.png`，只差那句标语，其余逐像素同源。两份 README 的 `<img>` 注释里
写清楚**改了画要重跑两次**，命令逐字可抄。

`scripts/render-hero.py` 相应加了 `--tint` 和 `--tagline` 两个参数，默认值就是仓里这两张
的参数，裸跑 `python scripts/render-hero.py` 出来的必须是 `docs/img/hero.png` 本身。
