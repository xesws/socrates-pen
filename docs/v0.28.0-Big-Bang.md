# v0.28.0 · Big Bang（实验功能）

默认仍是一场对话。右上角「＋ Agent」每次增加一场独立对话，最多四场；新 Agent 沿用当前面板的笔记和选段，不复制聊天记录。各场可以同时思考、输出、等待审批或停止。关闭某个面板会取消它的任务及待审批操作，已保存的会话历史仍在 sidecar 中。现有打开的面板与会话绑定会保存，重新打开插件后恢复。

## 自动分屏

布局依据插件内容区的宽高，不依据显示器方向。宽屏中的窄侧栏也会上下分屏。

| 数量 | 横向优先 | 纵向优先 |
| --- | --- | --- |
| 1 | 原来的单窗 | 原来的单窗 |
| 2 | 左右等分 | 上下等分 |
| 3 | 舒适时三列，否则左一右二 | 舒适时三行，否则上一下二 |
| 4 | 舒适时四列，否则 2×2 | 舒适时四行，否则 2×2 |

每个候选模板都检查最小尺寸 320×320 CSS px，间距 8px；三/四列需要每列至少 420px，三/四行需要每行至少 360px。不满足任何模板时，保留所有面板，纵向排列并允许外层滚动。窄于 320px 时适配侧栏实际宽度。方向有 10% 滞回，切入另一模板需留出 24px 余量，避免拖动断点时抖动。

布局函数只返回 CSS Grid 几何。面板节点、会话、输入草稿、焦点和流式连接不会因 reshape 重建。每场对话独立滚动；读旧消息时新输出不会强行滚到底。点击某个面板决定命令与后续活动笔记跟随的目标，其他面板保持自己的上下文。

## 文件一致性

`edit_file` 仍然用唯一匹配的 `old_string` 替换；行号是读取坐标。

- 每次读取同时计算正文的 SHA-256，版本与返回内容来自同一份读取。分段读取中途变化时返回 `FILE_CHANGED`，旧分页坐标不得直接沿用。
- 每个 session 分别记录读取版本。提案冻结基础版本；进入审批前检查一次，实际批准写入时再检查一次。
- 实际提交持有短文件锁：读取并检查版本 → 快照 → 唯一临时文件 → 原子替换。模型调用和等待用户审批不持有文件锁。
- 编辑、折叠写回、撤销和重做共用文件锁。文件别名不能绕过并发事务，临时文件不再使用共同的固定名字。
- 任何版本变化都要求重读、重新提案和重新审批，即使两场修改不同段落。旧审批没有版本时拒绝写入。压缩丢弃读取内容时同时撤销读取资格。
- 撤销/重做操作作用于共享笔记。界面标明最近编辑的来源；请求绑定显示时的文件版本与快照栈顶，期间发生新修改时要求刷新后再操作。

保证范围是同一 sidecar 进程内参与协议的插件写入口。Obsidian 手改造成的内容变化会被版本检查识别，但任意外部进程在校验和提交之间直接改磁盘，不在本版强一致性保证内。没有自动合并或共享 Agent 聊天历史。

## 运行与协议

每个面板使用自己的 session。聊天和审批请求携带 `run_id`，SSE 回传 `session_id` 与 `run_id`。`POST /v1/sessions/{id}/cancel` 只取消对应 run；等待审批时也可以按 `pending_id` 取消，不调用模型。取消完成前已经进入提交临界区的写入不会被回滚，之后的工具操作会停止。

`GET /v1/health` 广告 `capabilities.big_bang`。旧 sidecar 不能新增 Big Bang 面板；插件及 sidecar 版本更新为 0.28.0。原单 session 绑定兼容保留为 primary，额外绑定保存在 notes 的 agents 映射中。

## 验证

- `python -m pytest pen/tests -q`：原有回归及真实线程竞争、同/不同段落冲突、审批重启恢复、旧审批、分页过期、路径别名、撤销后旧提案、任务取消。
- `npm run build`：TypeScript、现有前端检查、布局矩阵和断点滞回，再构建插件。
- `python scripts/check-big-bang-ui.py [截图目录]`：可选浏览器集成检查，需要 Python playwright 与 Chrome/Chromium（可用 `CHROME_EXECUTABLE` 指定）。使用生产 PenView、布局和 API 代码，替换 Obsidian 宿主与模型响应；不调用真实模型、不连接用户 vault。

浏览器检查覆盖 1→4→1、多尺寸重排、DOM 身份与草稿/滚动保留、四路独立输出、过期事件过滤、单路停止、待审批时重排、关闭及中英/深浅色主题。拖动分隔线、自定义布局与布局动画留作后续升级。
