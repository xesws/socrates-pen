# v0.15.7 — 把书名注进 probe 的 user packet

> 日期：2026-08-21。插件 semver 不动（`src/` 一行不改，manifest 留在 0.13.1，不发 Release）。

## 病在哪

v0.15.0 只解耦了**主对话**那条路：`pen/session.py` 的 `SYSTEM_PROMPT_TEMPLATE` 开了 `{book}` 槽，
`pen/app.py:482` 建场时把 `meta.title` 注进去。

**深挖那条路没跟上。** `pen/probe.py:617` 的 `build_user_message` 是深挖线程发给模型的
唯一一份 user packet，它给了位置、原话、苏格拉底的回复、足迹、书架、已问过的题——
**唯独没给「这是哪本书」**：没书名，没 path。模型只能从 level / 拍名 / 材料里往回推。

v0.15.4 在 `PROBE_SYSTEM` 里加了一段免责话（「这五个例子取自另一本讲 SWE Agent 的手册，
只看形状别照搬名字」），那是**缓解**，不是**治根**：它让模型别抄那五个 SWE 名字，
但模型依然不知道手上这本讲什么。审查 Agent `reviewer-regression-2` 报的第 (c) 条，
逐字确认成立。

顺带一处同病：`[工作目录里还有这些教材]` 这块说的是「**还**有」——没有「这本」，
「还」就没有参照物。

## 改法（2 个文件）

> 前置：v0.15.6 已经把书名清洗抽成 `session.clean_book_title`。

### 1. `pen/probe.py`

清洗直接用 v0.15.6 抽出来的 `session.clean_book_title`。

- `ProbeJob` 加 `book_title: str = ""`。**给默认值**，理由和 `limits` 那条一样：
  必填要改十七处测试构造点。代价由 `test_app` 的透传断言兜住。
- `build_user_message` 最前面加一块：

  ```
  [你在带读哪本书]
  《从零手写 DQN · 强化学习通关手册》
  （下面所有材料都出自这本书。它讲什么，看材料——别从别的书上推。）
  ```

  书名为空就**整块不出现**，不要渲染出一个空的《》。
- `clean_book_title` 用 `from pen.session import` **延迟导入**，和 `_harvest`
  在 `:953` 的写法一致（probe 全仓不在模块级 import session）。

### 2. `pen/app.py`

`_maybe_probe` 加一个 `book_title` 形参，`:797` 的调用点传 `meta.title`——
`meta` 在同一个 `try` 里（`:708`）早就在手了，不额外读盘。

**不从 `sess.book_title` 取。** 那个字段**不落盘**（v0.15.0 的设计：
`messages[0]` 建场时就固化了，字段本身没必要跟着存），所以从磁盘恢复回来的
会话上它是空的——而深挖恰恰最常发生在读者聊了几轮之后。走 `meta` 才是每轮都真。

## 验证

| 项 | 怎么验 |
| --- | --- |
| 新断言① | 给了 `book_title` → packet 含《书名》，且书名块排在 `[读者刚才在读哪儿]` **前面** |
| 新断言② | 没给 → packet 里**不出现**「[你在带读哪本书]」，也不出现空的「《》」 |
| 新断言③ | 脏书名（带换行 / `.md` 尾 / 套书名号 / 超长）走同一套清洗，和 `_book_phrase` 结果一致 |
| 透传 | `test_app` 里断言 `_maybe_probe` 造出的 job 的 `book_title` 等于 `meta.title` |
| 不回归 | 两仓 `pytest pen/tests -q` 全绿（当前基线 480 passed） |
| 前端不受影响 | `npm test` + `npx tsc --noEmit` + `npm run build` |
| 两仓不漂 | `diff -rq --exclude=__pycache__` 两仓 `pen/` 无输出 |

## 不做的

- 不改 `PROBE_SYSTEM` 里那段免责话。根治了不等于缓解要撤——两条一起在，模型
  既知道手上是哪本，也知道那五个例子不是自己这本的。
- 不给 `PenSession.book_title` 加落盘。深挖走 `meta`，不需要它。
- `src/` / `styles.css` / `manifest.json` / `versions.json` 全程不动。
