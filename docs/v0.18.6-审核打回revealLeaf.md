# v0.18.6 — 审核打回：撤掉 revealLeaf 引用

> 日期：2026-08-23。0.18.5 提交商店审核被自动闸打回：
> `no-unsupported-api — src/main.ts:141, src/main.ts:141`。

## 病与根因

`activateView`（评测整改时加的「丝带必展开右栏」）用了 `revealLeaf`——
@since 1.7.2，而 `minAppVersion` 是 1.5.0。虽然当时做的是**能力探测**
（cast 后 `typeof === "function"` 才调），但审核闸按 `.d.ts` 的 @since 标注
**拦引用本身**，哪怕只出现在 cast 的类型注解里；一行两处引用正好对应报错
里的 "141, 141"。

## 改法

撤掉 revealLeaf，只走 `workspace.rightSplit.collapsed = false`（同为 1.5.0
时代的老 API）。E2E 实测（Obsidian 1.13.7，dev vault）：折叠右栏 → open
命令 → 展开 + 视图可见，重复两轮均过——`collapsed` 这条路本身就够。

同时用脚本把 `obsidian.d.ts` 全部 @since > 1.5.0 的 API 与 `src/` 全量交叉
扫描：除 revealLeaf 外**零命中**，下一版不会再在这道闸上被打回。

## 验证

| 项 | 结果 |
| --- | --- |
| 门禁 | tsc / npm test 七道闸 / 构建 + node --check 全绿 |

| @since 扫描 | src/ 中无其他超 1.5.0 API 引用 |
