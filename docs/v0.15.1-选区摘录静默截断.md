# v0.15.1 — 底栏选区摘录不再静默截断

> 日期：2026-08-22。插件 `0.15.0` → `0.15.1`。发 GitHub Release。

读者划了一大段「读图」，底栏 `.sp-quote` 看起来像模型输出被砍断。其实是两刀叠在一起：

1. `paintQuote()` 把选区 `slice(0, 420)`，**不标省略**
2. CSS `-webkit-line-clamp` 又没有 `text-overflow: ellipsis`

审批面板自己写过「静默截断会让他以为自己看全了」，选区摘录漏了同一条。

改法：DOM 放全文，裁剪交给 line-clamp，补上省略号，悬停能看到整段。
