# v0.22.5 — Gemini 的推理档

> 日期：2026-09-02。承读者试配 Gemini 时撞的一个 400。

## 读者说的

> 「google 这个好像配置的不太对」

截图里的红字（还是 v0.22.3 那条「转述节点原话」在干活）：

```
Error code: 400 - Invalid JSON payload received.
Unknown name "thinking": Cannot find field.  status: INVALID_ARGUMENT
```

**不是他配错了，是我们发错了。**

## 病灶

`thinking_wire()` 是全仓唯一按型号名分叉的地方，但它只认三家：celeris、GLM、
其余一律走 DeepSeek 那一支：

```python
out["reasoning_effort"] = lv
out["extra_body"] = {"thinking": {"type": "enabled"}}
```

`extra_body` 里的键会被 OpenAI SDK **摊到请求体顶层**。于是 Google 的兼容层
收到一个顶层 `thinking` 字段，当场 `INVALID_ARGUMENT`。

所以 Gemini 只有在 Thinking = off 时能用（那一档发的是空 dict），**其余三档
必 400**。

## 查到的事实

| 事实 | 来源 |
|---|---|
| 兼容层**自己就认 `reasoning_effort`**：minimal/low→low、medium→medium、high→high | 官方文档 |
| `thinking_level` 只有 `low` / `medium` / `high` | 官方文档 |
| **Gemini 3 起思考关不掉**；`reasoning_effort:"none"` 只对 2.5 有效 | 官方文档 |
| `stream_options.include_usage` 支持、function calling 支持 | 官方文档 |

> 这一版的事实是**文档来的，不是实测的**（手上没有 Gemini 凭据）。
> 和 `v0.22.0` 那张 celeris 表不同——那张每一行都是本机打过一枪量出来的。
> 差别写在这里，免得后来的人拿它当同等强度的依据。

## 改法

Google 文档给的那层嵌套是

```python
extra_body={'extra_body': {"google": {"thinking_config": {...}}}}
```

**没采用。** 裸的 `reasoning_effort` 文档同样写了支持，而且它已经是这个函数
的通用形状——引进第二种嵌套只会让这张表再多一种要维护的形态。

```python
if _is_gemini(model):
    if lv == "off":
        return {"reasoning_effort": "low" if _gemini_forced_thinking(model) else "none"}
    return {"reasoning_effort": lv}
```

「关不掉思考的型号，UI 的 off 落到最低档」这个处理仓里已有先例
（`_glm_forced_thinking`，GLM-5.3）。版本号认不出来时**按「关不掉」处理**：
发 `low` 最坏是慢一点、贵一点；发 `none` 给一个关不掉的型号是 400——
两种错的代价不对等。

## 闸

除了逐档比对返回值，还有一条**看线上形状**的：

```python
def test_no_model_sends_a_field_google_would_reject(...):
    for shot in rec.shots:
        assert "thinking" not in shot
```

只验返回值不够——`extra_body` 是被 SDK 摊平的，而闸要看的是「节点收到了
什么」。另外起了一个照 Google 规矩执法的假节点（顶层出现未知字段就 400），
四档跑通；把修复那一支关掉，`low/medium/high` 三档**逐字复现**读者那句报错，
`off` 照旧能过。

## 还没做的

这类事情每换一家供应商就会来一次，而读者要等到发一轮对话才知道。配置体检
（`v0.22.2`）目前**故意不带 thinking_wire**，也不带 `tools`、不流式——也就是
说，一个推理档方言不认、或者压根不支持工具调用的节点，状态栏会给绿灯。
下一版该让体检按主对话那一枪的真实形状打。
