# v0.18.0 — 评测报告五处整改

> 日期：2026-08-23。外部评测（对 v0.16.0）的整改，随 0.18.0 同车发布。
> 报告里「API key 存 vault」一条已由本版的主改动修掉（见
> [v0.18.0-API密钥迁出vault.md](v0.18.0-API密钥迁出vault.md)）；

## P0 没配钥匙时的失败态像坏了

**病**：没 key 时点 chip / Ask，面板追加一条 You、再追加一条**空**的 Socrates
气泡，光标一直闪，像在流式输出。真正的原因只在面板顶部一条红字。

**改**（`PenView.ts`）：
- `probeHealth` 把 `h.llm.ok` 存进 `llmOk`；`syncChipDisabled` 把它并进禁用
  条件——没钥匙时 5 枚 chip 和 Ask 全灰，Ask 输入框的 Enter 也不发。
- 真点了：不压空气泡，直接渲染**错误气泡**（`ChatMessage` 新增 `role:"error"`，
  只存在于前端，从不上行），无 key 时气泡上带「去设置」按钮（`app.setting
  .openTabById`，老版本 API 缺失时降级只开设置窗）。
- 流中途失败（provider 报错、网络断）：一个字没流出来就把空 assistant 气泡
  **原地换成**错误气泡（`failBubble`）；流了一半则保留半截正文、其后追加。

## P0 换选段默默清掉整段对话

**病**：会话按笔记绑定，切到另一篇必然换会话、面板清空——但一声不吭，读者
以为前两轮丢了。

**改**：`captureSelection` 在 handbook 变化且当前面板已有用户轮时弹 Notice：
「已切换到《X》的会话。原笔记的对话仍在原笔记上——再划它就能回来。」放在
分支之外——目标笔记有没有自己的旧绑定都该说；同笔记重划（同一场会话）和
renewed（同笔记换新场，自己有 Notice）不打扰。**不改会话模型**：按笔记绑定是
写回正确性的地基（选区字段和会话必须一起换，见 captureSelection 里的注释）。

## P1 右侧栏折叠时点丝带没反应

**改**（`main.ts activateView`）：`setActiveLeaf` 前先能力探测 `revealLeaf`
（1.7.2+ 才有，minAppVersion 是 1.5.0），没有就掰 `rightSplit.collapsed`。
两路都失败只剩 Notice「面板已在右侧栏打开」。

## P1 Chip 视口太矮，写回入口要滚

**改**（`styles.css`）：chip 按钮 `flex: 1 1 auto → 0 1 auto`（按自然宽换行，
不再撑满）；`.sp-chips` 默认 `max-height 6.4em → 8em`，420px/640px 两档容器
查询 9em→10em、12em→13em。写回 chip 的禁用态与 tooltip（「先回答一轮」）原本
就有，不动。

## P2 关掉插件 ≠ 停掉 sidecar

这是**有意的**（README 一直写明：多库共用一只 sidecar，A 卸载杀掉会打断 B）。
**改**是给它一个出口：新设置 `sidecarKeepAlive`（默认 `true` = 原状），desc
一句话解释这是本机 Python 服务、多库共用；关掉后 `onunload` 停掉**由本插件
拉起**的那只（`stopOwned`），别人拉起的从不碰。

## 顺手：设置文案空格

en/zh 的 `setDefaultHint` 补前导空格——之前英文 desc 以句号结尾直接拼
"Default 40."，显示成 `…won't get around it.Default 40.`。

**owned-kill 未做真进程 E2E 的原因**：让插件真正拉起 sidecar 会触发 venv 里
pen 的版本升级（拉 `0.18.0` tag——尚不存在——回退 `git+master`），把用户真实
venv 升到未发布代码。该路径 = `onunload → sidecar.stopOwned()`，`stopOwned`
的进程语义已被既有测试与「停止」按钮共用。
