# v0.15.13 — 版本闸盯全四家，以及我自己抄错的那个数

> 日期：2026-08-22。审查 Agent `reviewer-facts` 第三轮（只验 delta）。
> 它点名的六处全干净，另外找到 2 条——**都在我正在猎的那一类：写死的计数过期。**

## ① `npm test 162 项` 抄错了，实际 274，而且抄进了五份文档

`package.json` 的 `test` 脚本串跑**五道闸**：

```
check-i18n(57) && check-poll(26) && check-api(22) && check-css(7) && check-limits(162)
                                                                   = 274
```

**162 只是 `check-limits.mjs` 一家**——它是最后一个打印的，我把它当成了总数。
`docs/v0.15.2` / `v0.15.9` / `v0.15.10` / `v0.15.11` / `v0.15.12` 五份都带着它。

**最难看的是它长在 `v0.15.9` 里**——那份文档的全部主题就是「写死在注释里的计数会漂，
而且漂了没人发现」。同一页纸上我自己犯了同一种错。

五份都改成 `274 项（五道闸 57+26+22+7+162）`，**把构成写出来**，省得下次又有人
把最后一家当总数。两份 README 是干净的（README 的闸门表不报总数）。

> 改已经推上去的计划文档，这里破一次例：改的是**数字本身**，不是叙述、不是结论。
> 五份文档随仓公开，读者会拿它们当版本史读，留着一个错数比破例更糟。这条追记本身
> 就是那个「痕」。

## ② 版本闸只盯了一家，而漏掉的那三家正是下次会漏改的

v0.15.11 建的那道闸只断言 `pen/__init__.py == manifest.json`。审查随即指出：
`package.json` 和 `pyproject.toml` 仍然没人盯，下次发版漏改哪一家都不会变红——
**正是 v0.15.11 自己写下的那条规律**（没人读的常量必然过期）。

改成一次盯全，外加 `versions.json`（Obsidian 要求发布的版本登记在那张
version → minAppVersion 表里，漏登记会被插件市场直接拒）：

| 来源 | 今天 |
| --- | --- |
| `pen/__init__.py` | `0.13.1` |
| `manifest.json` | `0.13.1` |
| `package.json` | `0.13.1` |
| `pyproject.toml` | `0.13.1` |
| `versions.json` | 含 `0.13.1` |

**变异验过**：把 `package.json` 改成 `9.9.9` → `assert '9.9.9' == '0.13.1'` 当场红。

## ③ 「那边跳过是对的」是替读者下结论——和上一版刚修掉的那句同形状

v0.15.11 的 skip 措辞写的是「实验室仓的插件在 `obsidian/` 下，根目录没有
`manifest.json`，**那边跳过是对的**」。审查查出来：

| 实验室仓文件 | 版本 |
| --- | --- |
| `pen/__init__.py` | `0.13.1` |
| `obsidian/manifest.json` | **`0.12.13`** |
| `obsidian/package.json` | **`0.12.13`** |

`git log -- obsidian/manifest.json` 显示它自 `817ed79`（v0.12.13，实验室仓最后一次
动它）起没再动过。**跳过的地方恰好就是漂了的地方**，而那句「跳过是对的」把它盖住了。

> **v0.15.15 追记**：这一段原本把 `817ed79` 括注成「也就是插件迁进公开仓那一刻」——
> 挂错了对象。迁仓是**公开仓**的 `1362174`，晚 29 分钟，是另一个仓的另一个提交；
> `817ed79` 在公开仓里根本解析不出来，而这两份文档随公开仓发。

两边的 `src/` 确实真的分叉了（我实测：公开仓多一个 `sidecar.ts`，
`i18n/en.ts` / `i18n/zh.ts` / `main.ts` / `settings.ts` 四个文件内容不同），
所以那份**可能就是有意冻住的**。但没有任何地方写过这条政策。

**我不替作者改实验室仓那份插件的版本号**——那是他的发版决定，而那份插件不发布。
做的是三件事：
1. skip 的措辞改成**只陈述事实**，并在 docstring 里写清「跳过的地方正是漂了的地方」
2. `docs/v0.15.11` 加一条追记，把当时那句下结论的话标出来
3. README「还欠着的」加一条，中英都有，把事实和「可能是有意的」一起摆出来交给作者定夺
