# v0.17.0 — 给 sidecar 注册 Fetch 工具

> 日期：2026-08-22。插件 semver 仍是 `0.14.0`，不打 GitHub Release。
> 活代码在公开仓 `socrates-pen`；实验室仓 `pen/` 同步，因为本机 sidecar 跑在那边。

## 做什么

第三把模型工具：`fetch`。给定 http(s) URL，GET 回来，把正文交给模型。权限 `allow`，
对标 `read_file`。不是搜索，不点亮「查相关论文」芯片。

## 闸

- 只允许 `http` / `https`
- SSRF：loopback / 私网 / link-local / 未指定 / 组播，每一次跳转都再查
- `httpx.Client(trust_env=False, follow_redirects=False)`，超时 10s，正文截到 `MAX_OUTPUT`
- 计入已有的 `max_tool_rounds`

## 不做

不启用 search 芯片，不接搜索 API，不给 Fetch 审批，不发 0.15.0。
