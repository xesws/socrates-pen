# v0.19.2 — 换节点误导 Notice、Stop 后再 Start 误报没 Python、GLM Thinking 档

> 日期：2026-08-27。插件 `0.19.1` → `0.19.2`。

三条同一条设置链上的病，读者验证过后再发版。

1. **Stop 后再 Start 报「没找到 Python 3.11」。** Dock 打开的 Obsidian 经常看不见 Homebrew。旧逻辑先扫系统 PATH，家目录 `~/.socrates-pen/venv` 明明刚跑过也不用。现在 venv 对齐插件版本就直接 spawn；只有还没建过 venv 才找系统 python3（并补 `/opt/homebrew/bin/python3`）。落后版本用 venv 自己 pip，不找 PATH。
2. **DeepSeek 换成 GLM 弹出「本机 Base URL 指向 DeepSeek」。** 钥匙按主机落锁是对的，文案和空串回落不对。全选再贴时 onChange 立刻填回默认 DeepSeek；Notice 又先甩旧主机。现在空串留到失焦；文案改成「节点换了，钥匙不会拿到新主机上用」。
3. **GLM Thinking 档跟 DeepSeek 不是同一套。** 设置页仍是 off/low/medium/high。GLM-5.3 不能 `thinking=disabled`（会 400）：off 改成 enabled+low，不报错。high = 该节点顶档（GLM 是 max）。medium 在 5.3 没有，映射 high。DeepSeek 的 off 仍不传思考字段。400 不再叫人改回 off。

六家版本号齐到 0.19.2。装完请 Stop 再 Start，sidecar 才能装上 `thinking_wire`。
