## 一 · 三行没对齐

读者指出 `SOCRATES` 的 S、标语的「苏」、副题的 S 三个字头不在一条竖线上。
从 v0.16.6 那张成图里量（设备像素，2×；右栏左缘在 x=762）：

| 行 | 墨迹左缘 | 相对栏左缘 |
| --- | ---: | ---: |
| `SOCRATES` | 794 | **+16.0 CSS px** |
| `苏格拉底学习法` | 778 | **+8.0 CSS px** |
| `Socrates-agent` | 764 | **+1.0 CSS px** |

**病根是从插件那边照搬了 `text-indent`。** `styles.css:613-633` 的
`.sp-splash-tag` 写着 `text-indent: 0.34em`，那一条是**居中**布局用来抵消末字后
多出的一格字距的——插件那张启动卡是竖排居中。hero 的右栏是**左对齐**，同一条
`text-indent` 到这儿只剩一个作用：把首字往右推。推的量还各不相同：

- `#wordtext` `text-indent: 0.30em` × 44px = **13.2px**
- `#tag` `text-indent: 0.34em` × 20px = **6.8px**
- `#sub` 压根没写 indent = **0**

三行于是站成一道阶梯。横排模板里这两条 indent 全部删掉；`TEMPLATE_COL`（竖排、
居中）里的保留不动，那里它是对的。

### 去掉 indent 还差最后一步：字形左边承

排版原点对齐了，墨迹仍不对齐——每个字形自带左侧边距（left side bearing），
字号越大差得越多。所以新增 `ALIGN_JS`：在页内用 canvas 的
`measureText().actualBoundingBoxLeft` 量出每行首字的真实墨迹起点，再用等量负边距
把它拉回栏左缘。实测这三个值（出图时会打印）：

```
wordtext +2.99px   tag +0.98px（英文版 +0.88px）   sub +0.81px
```

拉回的目标选的是 `#rule` 的左端——分隔线横跨整栏，是这一栏视觉上的左边界。
于是字标、标语、副题、分隔线**四条**左缘落在同一根竖线上。

### 拿成图证明，不拿渲染器的说法证明

新增 `check_align()`：出图之后回头读**最终 PNG 的像素**，扫出右栏每行文字的墨迹
左缘，三行互相差超过 1 个设备像素就告警。中英两张都是：

```
右栏 3 行文字的墨迹左缘（相对栏左缘，CSS px）：+0.0  +0.0  +0.0
```

这条检查同时兼管越界：英文标语 `The Socratic Method` 在收窄后的右栏里
**只剩 20.0 CSS px 余量**。所以 `#tag` / `#sub` / `#wordtext` 一并加了
`white-space: nowrap`——宁可让它溢出边框被截图截掉（一眼看得见的失败），
也不要静默折行把右栏的纵向层级悄悄搞塌。`check_align()` 会把余量打出来，
逼近内缘就告警。

## 二 · 卡片长高 15%

肖像字号 `11px → 13px`（`PORTRAITS` 的默认值）：

| | 之前 | 现在 |
| --- | --- | --- |
| 卡片 | 840 × 411 | 840 × **473**（+15.09%） |
| 肖像 | 304.64 × 341 | **360.03 × 403** |
| PNG | 1680 × 822 | 1680 × **946** |
| 右栏可用宽 | 423.84 | 368.5 |

卡片高 = `1 + 34 + 31×fp + 34 + 1`，fp=13 正好 473。**宽度不动**，所以肖像变宽
就等量吃掉右栏：右栏从 423.84 收到 368.5。`SOCRATES` 仍是 44px，在新右栏里占
86%（原来 75%），离卡片内缘还剩 70.5 CSS px，不挤。

顺手把写死在模板里的 44px 提成常量 `WORDTEXT_PX`，并修掉一条**印了三版的假数字**：
之前那行日志印的 `SOCRATES(文字) @88.004px` 是 ASCII 字标那一档反算出来的字号，
而真文字档根本不走 `fw`，`#wordtext` 一直是 44px。现在印
`SOCRATES(真文字) @44px`，和 CSS 同源。

`PORTRAIT_WIDE` 仍不可用：同一条 473px 的高度下它的 51 行只能给到
`403/51 = 7.9px`，照旧糊成灰泥。narrow 那幅仍是唯一解。
