## 起因

读者要改的是 §1「为什么需要它」。要求插入一段话，一开始就讲清楚三件事：

1. 什么是苏格拉底学习法
2. 什么是费曼学习法
3. 为什么苏格拉底学习法比费曼学习法更好、更有实操意义

要把这个故事讲清楚，不能只把两个名字塞进原有段落里。

## 上一稿的病

上一稿（未提交）把费曼法放在苏格拉底法前面，并且把「定义」和「为什么更好」缠在同一段里：

- 读者先撞上费曼，再看到「走另一条路」，苏格拉底法本身是什么，要靠对比才能猜
- 「只问、先不讲」是产品动作，不是这种方法从哪来、做什么
- 「更可操作」落在一句破折号里，故事没有单独被讲完

## 这一稿怎么讲

紧接「通用聊天机器人补不上这个位置」之后，用三段把故事讲完，再接到原有的
「所以它全部的设计都从一句话长出来」：

| 段 | 讲什么 |
| --- | --- |
| 1 | **苏格拉底学习法是什么**：苏格拉底几乎不讲课，坐在旁边追问，答案是被问出来的；读者不必先组织一整段讲解，接住一个问题即可 |
| 2 | **费曼学习法是什么**：用自己的话讲给假想外行听，讲不下去就是没懂；靠输出，入口是「你已经能开始讲」 |
| 3 | **为什么前者更有实操意义**：啃长手册最难受的时刻卡在这个入口之前；费曼法一张纸就能做，苏格拉底法一直缺的是旁边那个人；卡住的那一刻就能上手，不必等自己先变成老师 |

写作规范沿用 v0.16.0：每段 3–6 行，每段最多一个破折号，§1 不出现版本号和代码行号。
中英文镜像，不改 §2 及之后。

## 审查后改了什么

两路 Kimi K3 都判 fix-then-ship。采纳的：

- 第三段结尾不再用「所以它」，避免和下一段「所以它全部的设计」连着两个「所以」、两套先行词
- 第三段不再提前写出「读过这本书、知道你读到哪一行」，把这句话留给后面那句加粗的设计提纲
- 「更有实操意义」收成「这一点费曼法够不着」，只主张卡住那一刻，不和「懂了八成之后费曼很管用」打架
- 费曼段「你得先能开口讲 / 你已经能开始讲」说了两遍，第一遍改成「你得自己开口讲」
- 英文 `doorway` 改 `threshold`；bare "Socratic" 补成 "the Socratic method"；"has always needed" 改成 "has always been missing"，对齐中文的「缺」
