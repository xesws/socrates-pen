## ① 事实错误（4 条，全部复验成立）

### 1. 隐私段里那句承诺，沙箱给不了 —— 这条最要紧

原文：「**它不会读你整个 vault。** 只读你划词的那一篇，加上你自己放上书架的那几本。
不索引、不遍历、不上传。想放宽读的范围得你自己登记。」

**我隔离环境实跑过**：临时 vault 里登记 `book.md` 之后

```
assert_readable(book, "私人/日记/2026.md", extra_roots=[vault]) → 放行
```

链路：`src/views/PenView.ts:788` 把 `vaultRoot(app)` 当 `vault_root` 发出去 →
`meta.allow_root` → `pen/tutor.py:69` `read_roots()` 返回 `[REPO_ROOT, *extra_roots]` →
`pen/sandbox.py` 的 `assert_readable` 只挡 `.git` / `.obsidian` / `.env*`。
**库根是插件自动登记的，不需要读者放宽。**

真话是：不索引、不遍历、不上传 ✅；实际只读那两类 ✅——但那是**行为**，
因为提示词只告诉了它这些，**不是沙箱保证**。改成照实说，并把 4.4 也一起加硬
（原来只写「读可以放宽到白名单里的根」，没说那个根就是整个库根）。
