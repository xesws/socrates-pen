## M1 · 「插件每升一版会再拉一次」是无条件写法，实际有条件

`src/sidecar.ts:186-190` `runEnsure` 第一件事就是：

```ts
if (await ping(opts.sidecarUrl)) { this.set("running", ""); return; }
```

**ping 通就直接返回，根本走不到版本比对。** 旧 sidecar 还活着的时候（禁用插件不会停掉它），
插件升级也不会重新下载。改成有条件：只有 ping 不通、需要重新拉起时才比对版本号。

涉及 §1 / §4.1 / §5 三处，中英各三处。

## M2 · §5「要彻底停掉去设置页点停止」是假话

`src/sidecar.ts:172` `stopOwned()` 第一行 `if (!this.owned || !this.child) return;`，
而 `owned` 初值是 `false`（`:141`）。文件头注释第 3 行自己就写着：
「不是我们拉起的进程，停止按钮不会去杀。」

插件重载/升级后是新的 `SidecarManager` 实例，`owned` 回到 false，此时点「停止」直接
return，什么都不会发生。改成实话：那个按钮只管本次启用里由插件自己拉起的进程。

（这条是旧文字，不是第一轮改出来的，但属同一类错误——描述了一个用户能观察到的行为，
而代码不是那样。）

## M3 · §2 第 2 步漏了「用当前选区」

`src/views/PenView.ts:943-946`：

```ts
if (!this.sessionId || !this.quote) { new Notice(t().noticeUseSelectionFirst); return; }
```

划完词直接点芯片，`send()` 在守卫处就被弹回，只会看到一条 Notice。§5「用」第 2 步写对了，
