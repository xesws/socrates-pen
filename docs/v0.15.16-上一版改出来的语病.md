# v0.15.16 — 上一版改出来的语病

> 日期：2026-08-22。**自查**。v0.15.15 把「漂了三版」改成「落下了后面那两个发布」时，
> 只换了名词短语，没跟着调句子，结果两处读不通。

## 病在哪

```
原句：所以漂了三版都没人发现
v0.15.15：所以它落下了后面那两个发布都没人发现     ← 「了…都」不搭
v0.15.16：所以它一连落下两个发布都没人发现
```

两处，`pen/app.py:61` 的注释和 `pen/tests/test_app.py:1030` 的 docstring，
两仓各一份。

## 为什么单独记一版

它本身只是一个语病，但**成因值得记**：v0.15.15 是一次六处多点编辑，我核对了
「数字改没改对」「有没有误伤别处」，**没核对「改完这句话还通不通」**。
前四轮审查逮到的错清一色是「写死的数」和「替读者下结论的话」两类，
我的自查也就只盯着这两类——**检查清单本身产生了盲区**。

## 验证

两仓 `pen/app.py` / `pen/tests/test_app.py` 逐字节一致；公开仓 487 passed。
