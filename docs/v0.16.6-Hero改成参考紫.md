# v0.16.6 — Hero 底色换成读者点名的那个紫

> 日期：2026-08-22。只动 `scripts/render-hero.py` 和 `docs/img/hero*.png`。
> `src/` `pen/` `styles.css` `manifest.json` `versions.json` 一行不动，不发 Release。
> 插件 semver 仍是 `0.13.1`。接上一版 [v0.16.5](v0.16.5-Hero标语与紫底.md)。

## 病在哪

v0.16.5 的底色是按 `styles.css:559-565` 那条 `color-mix(accent 24%, #241E30)` 算出来的，
出来 `#3C2D60`。读者退回了，原话是「这个紫色更高贵一些，你现在那个紫色有点太浅了」，
并给了一张样图。

量了两边就知道「太浅」是哪两条：

| | 色相 | 饱和度 | 明度 |
| --- | ---: | ---: | ---: |
| v0.16.5 的最亮端 `#3C2D60` | 257 | **36** | **28** |
| 读者给的 `#30293D` | 261 | **20** | **20** |

亮 8 个明度点，饱和度高 16 个点。**饱和度那条才是主犯**：把一支高饱和的强调色直接
当底色兑，出来的是廉价的紫；压住饱和度、压低明度，才是那个稳重的紫。上一版的公式
没错，错在拿它当底色用——那条 `color-mix` 在插件里是嵌进暗色 UI 的，周围全是暗的，
它显不出饱和；单独摆在白页上就显了。

## 改成什么

`#30293D` 定为 `REFERENCE`。它不是审美偏好，是**插件在读者主题下的实际底色**：
`docs/img/shot-01-splash.png` 里 22.5% 的像素恰好是这个值，铺满启动卡的整个上半幅。
读者截给我的，就是他自己每天打开插件看到的那张卡。hero 用它，README 顶上那张卡和
读者第一眼看到的那张就是同一个紫。

`TINTS` 不再存 `(base, ratio, ratio)` 让代码去算，改成直接存三个色标。默认档 `noble`：

```
linear-gradient(150deg, #30293D 0%, #2A2436 60%, #241F2E 100%)
                        L 20.0      L 17.6      L 15.0
```

三个色标的**色相与饱和度全部钉死在参考色上（H261 S20），只动明度**——整张卡因此
只有一个紫，不会混进第二个色相。而且参考色本身就是最亮的那一端：卡上没有任何一块
底色比读者点名的那个紫更浅，这是对「太浅」的直接回答。

另加一档 `noble-lift`（`#393148 → #30293D → #272132`），把参考色挪到中间、顶端再抬
4 个明度点，渐变更看得出来。没选它，因为它的左上角还是比读者给的那个紫亮。
`faithful` 保留，那是照搬插件公式的对照组。

顺手修回两个偏亮的值：

- **边框 `0.22 → 0.18`。** 18% 是 `styles.css:569` 的原值
  （`border: 1px solid color-mix(in srgb, var(--interactive-accent) 18%, transparent)`），
  上一版的 0.22 既不是原值也偏亮。实测也对得上：读者样图圆角上的描边合成后是
  `#3D315D`，按 `ACCENT` 反解 α ≈ 0.16。
- **分隔线 `0.30 → 0.26`。** 这条线是 hero 自己加的（插件那张竖排卡没有分隔线），
  没有可照搬的原值；底色压暗之后 0.30 显得跳。

`ACCENT = #8A5CF6` 不变，但它现在只管边框和分隔线，**不再参与底色**。

## 两条 assert

色值全部落成字面量了，所以得有东西钉住它们，否则半年后没人知道 `#2A2436` 是怎么来的：

1. `faithful` 那三个值必须等于 `color-mix(accent 16%/4%, #1E1E1E)` 的计算结果。
   公式改了、字面量手抖改了，导入时就炸。
2. `noble` / `noble-lift` 的每个色标，色相偏差 ≤ 1.5°、饱和度偏差 ≤ 1.0，对着 `REFERENCE` 算。
   这条真的拦下过一次：`noble-lift` 的尾色第一版写的 `#262131`，H258.75，差 2.25° ——
   8 位色在低明度下一个 LSB 就能把色相推走两度。换成 `#272132`（H261.2）才过。

## 验证（全部实跑）

| 项 | 结果 |
| --- | --- |
| 色准 | 成图最亮端底色 `#2F283D`，对参考色 ΔRGB = 1.4（192 色量化的漂移），肉眼同色 |
| 尺寸 | 两张都 `1680×822` = `840×411` 的整 2 倍 |
| 体积 | 70.4 KB / 69.6 KB（上一版 79.1 / 80.8），预算 ≤ 120 KB。渐变跨度变窄，色阶变少，所以更小 |
| 可复现 | 各连跑两次，md5 一致：`1cb029d9…` / `a2d19ed5…` |
| 对比度 | 肖像区 7.70:1、右栏 11.88:1（上一版 7.64 / 11.80），门槛 ≥ 6.0 |
| 圆角 | 四角 `alpha == 0` |

README 没改：`alt` 里写的是「紫色渐变卡片」，两条重跑命令的参数也没变（默认档换了名字，
但裸跑 `python scripts/render-hero.py` 出来的仍旧是 `docs/img/hero.png` 本身）。
