# v0.20.0 — 对话框可贴图

> 日期：2026-08-30。插件 `0.19.2` → `0.20.0`。

设置里「模型名」下面加 **图像理解** 开关（默认关）。打开后可在对话框粘贴或拖入 png / jpeg / webp / gif（最多 4 张、每张 2MB）。发给节点的是 OpenAI 兼容的 `image_url` 多段 content，不是新工具。

关着贴图：不发请求，气泡指向设置。节点拒收：同一类人话，不跟 Thinking 400 混。落盘丢掉像素，避免会话 JSON 被 base64 撑爆。未 compact 的内存里还留着，方便追问「左上角是什么」。

DeepSeek 文本模型请关；GLM / Qwen 等多模态再开。

六家版本号齐到 0.20.0。装完请 Stop 再 Start，sidecar 才能认图。
