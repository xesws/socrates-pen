## 病在哪

开篇引用块现在是这三段：

> 在 Obsidian 里划中一段，侧栏坐着一个人，先不给你答案，先问你一个问题。
>
> 他手里只有两把工具：读你的笔记、改你的笔记。……磁盘上才会动一个字节。
>
> 他跑在你自己的电脑上。没有作者的服务器。

三处都错：

1. 「侧栏坐着一个人」没有主语，也不通顺。
2. 读/改/允许是机制，不是卖点；「没有作者的服务器」用户不在乎，隐私留给 §5。
3. 真正的卖点是**苏格拉底学习法的两面**，旧稿只写了提问那一面，还写成了卖关子。

## 改成什么

开篇只讲践行苏格拉底学习法意味着的两件事：

| | 卖点 | 不是 |
| --- | --- | --- |
| 1 | 你可以不断追问；疑问被实时解答；解答能写回笔记，不会丢掉；想吃透哪一块都能吃透 | 审批闸、磁盘字节 |
| 2 | 苏格拉底式提问：它不断问你，把理解压深 | 「先不给答案」当作唯一动作 |

「跑在你自己的电脑上 / 没有作者的服务器」从开篇拿掉，§5 隐私段不动。
读先于写、点「允许」才落盘，仍在 §2 的五步里讲，开篇不再抢戏。

英文副题目前是 *Highlight a passage in your own notes, and get questioned*，只覆盖第二面，
和中文副题「苏格拉底学习法，深度学习任何一本教材」也不对称。这一版改成同一句话的英文。

写作规范沿用 v0.16.0：每段 3–6 行（引用块引子可短），每段最多一个破折号，加粗只给关键词。
中英文镜像。不改 §1 及之后的论证。

## 审查后改了什么

两路 Kimi K3 都判 fix-then-ship。采纳的：

- 「所有疑问都会被实时、快速地解答」收成「你尽管问这本书。疑问会被当场解答」：去掉和
  §3.3「默认芯片不直接给答案」打架的全称句，也去掉「实时、快速」叠词
- 「让你把这个知识点的理解」补上「对」；「对着…把…」中间加逗号
- 英文 "hold on that point is driven one layer deeper" 改成 "grasp of that point goes one layer deeper"
- "so it is not lost" 改成 "where it stays"；副题去掉那一逗号
- 第二面用「反过来」扣住第一面，避免「它」悬在标签上找不到主语
