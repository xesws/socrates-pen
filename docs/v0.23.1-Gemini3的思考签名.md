# v0.23.1 — Gemini 3 的思考签名：产出它的那一枪要把它带回去

> 日期：2026-09-02。读者换到 Gemini 就撞红字，而红条上一个字都没说清楚。

## 读者看到的

```
节点拒绝了这次请求：Error code: 400 - [{'error': {'code': 400,
'message': 'Request contains an invalid argument.', 'status': 'INVALID_ARGUMENT'}}]
```

「Request contains an invalid argument」——哪个 argument？没说。这就是整件事
最难的地方：**Google 在历史长的时候把真话咽回去了**。同一个错误，历史只留
5 条时它肯说：

```
Function call is missing a thought_signature in functionCall parts.
```

## 怎么找到的

对着读者自己那台节点二分。先排除我们自己发的那一枪：

| 打出去的 | 结果 |
|---|---|
| 裸请求（只有 messages） | ok |
| + `reasoning_effort=medium` | ok |
| + `stream` + `stream_options` | ok |
| + 三个工具 schema | ok |
| **全形状 = 我们真发的那一枪** | **ok** |

也就是说 v0.23.0 那张方言表和体检都是对的，问题在**历史**里。再对 60 条历史
二分——只在合法边界上切（切在 assistant 的 `tool_calls` 之后会造出一个没有
工具结果的孤儿调用，那本来就非法，第一版二分被它带偏过）——最短能挂的前缀
是「一次工具往返」。逐个变量试到第 5 组，节点终于说了实话。

## 病根

Gemini 3 在**每个** tool_call 上挂一个签名：

```json
{"id": "call_297731", "type": "function",
 "function": {"name": "get_weather", "arguments": "{\"city\":\"北京\"}"},
 "extra_content": {"google": {"thought_signature": "EoYCCoMCARFNMg/vBOfJ…"}}}
```

下一枪回传时必须原样带回。缺了就 400。

**这是同一个病的第三次发作。** v0.22.4 是推理正文（`reasoning_content` 不带
回去，DeepSeek 就 400），`_StreamedMessage.model_dump` 的注释里写着那次的
结论：「产出它的那一枪要把它带回去」。这次换了个字段，我们又犯了一遍。

## 两条独立的挂法

### 一、我们把节点给的东西扔了（同一家产的往返）

`_ToolCallDraft.__slots__` 只有 `id` / `name` / `args`。分片上别的字段整个
丢掉——**也就是说全程只用 Gemini，第一次调工具之后这轮对话就再也发不
出去了**。

修法不认字段名，只认来路：**分片上带的，原样留住、原样带回。** 写死
`extra_content` 一个键的话，下一家换个名字我们还得再修一次。只收非空值：
后续分片不带签名，不能把前面那片留下的盖成空。

真机对照：抹掉这一句，第二枪当场 400；带上，第二枪正常作答。

### 二、跨厂商的历史（Fast Mode 的常态）

`_switch_to_base` 的注释写着：

> **不回滚任何消息。** `session.messages` 是供应商中立的，换个 client 接着发就行。

Gemini 3 把这句话废了。Fast Mode 的快轮是**另一家**——快轮（比如 Celeris）
产的 tool_call 身上没有 Google 签名，切回基座的第一枪就是同一个 400。读者
中途换厂商的会话也一样，而且那些历史**改代码也救不回来**。

这不是边角情况：Fast Mode 是主力功能，两边不同家是常态。读者当时的配置正是
主 Gemini + 快 Celeris。

出路是**压平**：发给要求签名的那一家之前，把没有签名的工具往返转成文本。

```
assistant + tool_calls  →  assistant 文本：「（我调用了 read_file，参数 …）」
配对的 tool 结果        →  user 文本：「（工具返回）…」
```

压平丢的是**结构**，不是信息：模型照样读得到调了什么、参数是什么、结果是
什么，只是不能再引用那个 `call_id`。对**已经执行完**的往返来说这没有损失——
它们早就跑完了，没人会再去引用。

规则住在 `pen/providers.py`：

```python
# 这家要求 tool_call **原样带回**的那个签名，在 tool_call 里的路径。
# 空元组 = 不要求（绝大多数家）。
sig_path: tuple[str, ...] = ()
```

九家里只有 `google` 非空。动作挂在 `llm_create_kwargs` 上——**那是「主对话
那一枪长什么样」的唯一定义点**，体检也调它，别处补一遍就是第二个定义点。

签了名的那些一条都不动（否则第一条修复就白做了）；别家**返回同一个列表
对象**，连拷贝都不做。

## 闸

十二条，两个方向各自验过会红：

| 动什么 | 红几条 |
|---|---|
| `done()` 不带 `extra` | 3（分片字段 / 存进 history 的那条 / 走完整条路） |
| 抹掉 google 的 `sig_path` | 5 |
| 让 `signed` 恒判 False（连 Gemini 自己产的也压） | 4 |

还有一条反向闸：给个没有 `model_dump` 的光板对象，照样拼得出来——**多留
字段是锦上添花，拿不到就当没有，不许因此炸掉整轮对话**。
