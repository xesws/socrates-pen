# v0.18.2 — 面板跟随活动笔记 / 对话前 chip 视口 / i18n 星号扫尾

> 日期：2026-08-23。0.18.1 复测的两个洞 + 一处漏网的扫尾。

## ① 命令指向 A 后，面板不许再挂着 B 的内容

**复测实锤**：回到贝叶斯跑命令，面板仍是虚拟内存那轮/那条 quote，旧线程不回来；
无选中切笔记时旧 quote 也不清。根因：null-pick 恢复分支的 `errSessionGone` 与
无绑定两个出口**只设红条不碰面板状态**——绑定会话已被清理时走前者，面板原样
留着 B 的线程和引文，错误文案却在说 A。

**改**（`PenView.captureSelection`）：三个出口统一以活动笔记为面板上下文——
会话存活 → adopt 恢复（已有）；已清理 → `retargetEmpty()` 清成 A 的空态
（capturedPath=A、quote/msgs/chips/dyn 清空、sessionId 置空），红条保留，
重新划一段即开新场（chips 随新会话回来）；A 无绑定 → 同样清空 + errNoSelection。

## ② 错误气泡一出现 chip 就缩回 2–3 条

`is-splash` 的条件是 `msgs.length === 0`——错误气泡也是一条消息，立刻退出
放开态。改：类更名 `is-prechat`，条件放宽为「**还没有用户轮**」
（`!msgs.some(m => m.role === "user")`）：纯错误/纯工具态不再触发上限，首轮
真实对话后恢复有界滚动。深挖的动态芯片只在真实轮次后出现，这个窗口内没有
堆高风险。

## ③ i18n 星号扫尾 + 机械闸

0.18.1 只修了 probe 那一对（grep 输出截断漏扫）。本轮修齐 zh/en 各三处：
`**工具循环**`/`**tool loop**`（Token cap per turn）、`**当前这本**`/`**this**`
（跨书读）、`**同时开着多个库…**`/`**With several vaults…**`（全局在飞数）。
并给 `check-i18n.mjs` 加闸：两表所有字符串字面量不许含 `**` 或反引号——
踩过的坑挂看门狗，下回谁再写 Markdown 进 desc 当场红。
