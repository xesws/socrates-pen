# v0.17.1 — Fetch：钉死解析到的 IP，畸形 URL 不得打崩整轮

> 日期：2026-08-22。接 v0.17.0。插件 semver 仍是 `0.14.0`，不打 Release。

审查指出三处：解析和连接之间 DNS 能换答案；`urlparse` / `port` 抛 ValueError 会
把整轮对话打成 `chat.unexpected`；`resp.content` 先把整页读进内存再切片。

这一版：连到已经查过的那个公网 IP（Host / SNI 仍用原名），畸形 URL 变成工具错误，
正文用 `stream` 读到 `FETCH_MAX_BYTES` 就停。
