# v0.15.0 — 把教材从 prompt 里解耦

> 日期：2026-08-21。插件 semver 不动（`src/` 一行不改，公开仓 manifest 留在 0.13.1，不发 Release）。
> 这一版只改 sidecar 的 `pen/`，两仓同步。

## 病在哪

`pen/session.py:52` 的 `SYSTEM_PROMPT` 是**每一场会话 `messages[0]` 的全部内容**
（`session.py:171-173` 在 `__post_init__` 里写死并落盘）。它开头就把书写死了：

```
:52  你是苏格拉底，坐在读者旁边，正在带人读一本手搓 SWE Agent 的通关手册。
:53  读者才是主修这本手册的人。手册里的 Agent 是「记性为零、胆子极大」的实习生——你不要替实习生写作业。
:62  - examples：只给两个例子，名字必须对得上该 Level 第七拍（scan.sh、messages.append、dispatch、approve…）。
```

v0.14.0 让 sidecar 在**没有**那本手册时也能起来，但没治这条：**导进来的任何一本书，
模型都会被告知它在读一本 SWE Agent 手册**，`examples` 芯片还会被四个 SWE 专属的
名字往那本书上带。要给 README 造一本强化学习教材做演示，第一句就撞上它。

## 面积有多大

全 `pen/` 扫过一遍，**写死 SWE 的只有上面三行**：

- `pen/probe.py:78` 的 `PROBE_SYSTEM` 本来就是书无关的（「你是这本手册的助教」），
  `:353` / `:428` 已经明写「『第三拍 · 出身』是本手册特有的八拍体例，别的书没有」——
  八拍是**格式契约**，不是 SWE 的内容。不动。
- `pen/config.py:34` 的 `DEFAULT_HANDBOOK` 仍指向 `SWE-Agent通关手册v2.md`，
  但 v0.14.0 已让 `ensure_default()` 在文件不存在时空操作。不动。
- `pen/index.py:149` 的 `if i == 1 or heading.startswith("手搓")` 是遗留特判；
  第 1 行 H1 那条通路对任何书都成立。不动。
- `pen/diagnose.py:53` 的 `"dispatch"`、`pen/questions.py:32` 的注释——
  启发式词表和注释，不影响别的教材能不能用。不动。

## 做什么

书名从哪来：`build_index` 把**第 1 行 H1** 存进 `HandbookIndex.title`
（`index.py:126,149-150`），fallback 是文件名。`app.py:469` 的
`_meta_or_404(body.handbook_id, lang)` 已经把 meta 拿在手里了。

1. **`pen/session.py`**
   - 拆出 `SYSTEM_PROMPT_TEMPLATE`，留一个 `{book}` 槽。
   - **`SYSTEM_PROMPT` 这个名字保留**，语义变成「不带书名渲染出来的默认串」——
     `pen/tests/test_questions.py:108` 和 `pen/tests/test_agent.py:1226` 直接
     import 它做断言，删了就是无谓的连坐。
   - 第 1 行：有书名 → 「正在带人读一本叫《{book}》的通关手册」；
     没有 → 「正在带人读一本通关手册」。
   - 第 2 行不再提「SWE Agent 的实习生」，改成书无关的说法。
   - `examples` 芯片不再点名 `scan.sh` / `dispatch`，改成「对得上该 Level
     第七拍里**真出现过**的东西」。
   - `system_prompt(lang="zh", *, book_title="")`；`PenSession` 加一个
     `book_title: str = ""` 字段；`SessionStore.create(...)` 透传。
2. **`pen/app.py:467-482`** — 把 `_meta_or_404` 的返回接住，取 `title` 传给 `create`。

## 不做

- **不改落盘 schema**。`messages[0]` 建场那一刻就固化了，旧会话原样留着——
  这和 `lang` 中途切换不影响已有会话是同一条既有语义（`session.py:153-155`）。
  所以 `book_title` 不进 `to_dict()`。
- 不动 `probe.py` 的 `PROBE_SYSTEM`。
- 不动前端一个字节，不发 Release。

## 验证

- `python -m pytest pen/tests -q` 全绿，重点看碰过 prompt 的五个：
  `test_session` / `test_i18n` / `test_questions` / `test_agent` / `test_probe`
- 新增断言：① 给了书名 → 含书名且**不含** "SWE"；② 没给 → 不含 "SWE"，
  也不留空书名号；③ `system_prompt("en", book_title=…)` 仍带英文尾巴；
  ④ 旧会话 JSON 加载后 `messages[0]` 一个字节不变
- 端到端：起临时 sidecar 导一本别的书，`POST /v1/sessions` 后直接读
  `.pen/sessions/<sid>.json` 的 `messages[0]`，断言里面是那本书的书名
- 两仓不漂：`diff -rq --exclude=__pycache__ pen ../socrates-pen/pen` 无输出
- 公开仓 `npm test` + `npx tsc --noEmit` 不受影响
