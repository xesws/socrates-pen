## 顺手挖出来的两条真 bug（都写进「还欠着的」，没修）

1. **`libraries._suggest_id` 会吐出后端自己不收的 id。** 它保留 CJK
   （Python 里 `'从'.isalnum()` 是 `True`），而 `_SAFE_ID`（`libraries.py:20`）
   只认 `[A-Za-z0-9._-]`。插件撞不到，因为 `src/selection.ts:30` 的
   `handbookIdFromPath` 会把非法字符全换掉再补路径哈希——但直接打 HTTP 会撞 400。
   这条就是采集第一步真撞出来的（`{"detail":"非法 handbook_id：'从零手写dqn'"}`）。
2. **英文界面 + 中文教材时，主对话经常仍然用中文回答。** system prompt 是中文的，
   英文只是尾部追加的 `REPLY_IN_ENGLISH`（`session.py:117`），一整篇中文正文压过来顶不住。
   有意思的是**后台深挖那一层不受影响**——它 prompt 更短，英文那一场抛回来的题是英文的。
