## 脱敏

**一处真打了码。** `shot-04-approval.png` 里那行 `edit_file → …` 原本是作者的真实路径
（含用户名和 vault 名）。README 正文里 vault 路径**零出现**、一律写 `/Users/you/…`，
`docs/demo/transcripts/README.md` 也专门声明过「唯一改动是把绝对路径换成 `/Users/you/…`」——
图不能破这个口径。

做法不是打黑条，是按原样重绘：从原图量出 Menlo **19px**（`edit_file` 九个字符 ink 宽 100px、
高 18px，Menlo 19 渲染是 98×18）、背景 `(28,28,28)`、字色 `(202,202,202)`、基线 y=958，
然后 ASCII 用 Menlo、汉字用 Hiragino Sans GB（19px 正好全宽）沿同一基线重写成
`/Users/you/vault/从零手写DQN.md`。

**其余七张查过，干净**：设置页那张 API Key 框是空的（只有灰色 placeholder `sk-…`），
Base URL 是公开端点；状态行里的 `DEEPSEEK_API_KEY` 是**变量名不是值**。
截图时左侧文件浏览器是收起的，所以那本没随仓公开的手册的文件名没有出现在任何一张图里。

## 体积

RGB + `MAXCOVERAGE` 256 色 + `dither=NONE` + `optimize=True`，**5.2 MB → 1.57 MB（省 70%）**，
文字和 ASCII 密度字符都没糊（逐张放大核过芯片行与字标）。
`shot-02-socratic.png` 另外压掉了中间 1112px 的纯空白带（回答短、窗口高，那段什么都没有），
2000px → 968px；只删空白，不动任何内容。
